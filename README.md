# Hyperion Drone Controller

Учебное Android-приложение для поэтапной разработки пульта управления дроном.

## Версия 0.2 — подключение к Wi-Fi

- Приложение открывает системные настройки Wi-Fi Android.
- Пользователь выбирает сеть квадрокоптера и возвращается в приложение.
- Экран показывает имя текущей Wi-Fi сети и адрес шлюза, если Android их предоставляет.
- Кнопки полёта пока демонстрационные и не отправляют команды дрону.

Для чтения имени Wi-Fi Android требует разрешение на местоположение и включённые службы геолокации. Приложение запрашивает разрешение при попытке подключить или проверить сеть. Открытие Wi-Fi настроек выполняет системный экран Android; пароль вводится там.

## Сборка APK

Нужны Flutter 3.38.1 или новее, Android SDK и JDK 17. Для локального запуска и сборки в корне проекта выполните:

```bash
flutter pub get
flutter run
flutter build apk --release
```

Готовый APK появится по пути `build/app/outputs/flutter-apk/app-release.apk`. GitHub Actions также собирает APK после каждого push в `main`; его можно скачать из раздела Actions как артефакт `hyperion-drone-controller-apk`.

## Этапы

1. Версия 0.1: экран с демонстрационными кнопками.

3. Следующая версия: проверка связи с дроном и тест одной команды/мотора.
