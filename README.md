# Hyperion Drone Controller

Учебное Android-приложение для поэтапной разработки пульта управления дроном.

## Версия 0.7 — макет четырёх моторов

- Приложение открывает системные настройки Wi-Fi Android.
- Пользователь выбирает сеть квадрокоптера и возвращается в приложение.
- Экран показывает имя текущей Wi-Fi сети и адрес шлюза, если Android их предоставляет.
- Кнопка проверки отправляет E88 heartbeat по UDP и показывает, ответил ли дрон.
- После ответа приложение продолжает проверку, показывает задержку и время последнего ответа.
- Если подтверждённый дрон не отвечает больше 4 секунд, статус меняется на «Дрон не ответил»; при возобновлении ответов статус восстанавливается.
- Во время активной сессии доступна кнопка отключения; она останавливает heartbeat и освобождает сетевую привязку приложения.
- При сворачивании приложения активная сессия останавливается. После возврата нужно проверить связь снова.
- Добавлены четыре независимых канала демо-моторов M1–M4 с условной мощностью до 30% и отдельными кнопками запуска/остановки симуляции.
- Кнопка «Остановить все моторы» завершает все четыре симуляции.
- Симуляция не запускает физические моторы и не отправляет пакеты управления.
- Для молчащих E88 плат выполняется Wi-Fi mode switch, но экран честно помечает связь как неподтверждённую.
- Команды взлёта, посадки, стиков и моторного управления пока не отправляются.

Для чтения имени Wi-Fi Android требует разрешение на местоположение и включённые службы геолокации. Приложение запрашивает разрешение при попытке подключить или проверить сеть. Открытие Wi-Fi настроек выполняет системный экран Android; пароль вводится там.

В исходном приложении для E88 описаны общие команды управления полётом, но отдельной команды для запуска одного выбранного мотора нет. Поэтому четыре канала в версии 0.7 — только интерфейсный макет. Физическое управление появится с полной версией приложения, которую добавит её автор.

## Сборка APK

Нужны Flutter 3.38.1 или новее, Android SDK и JDK 17. Для локального запуска и сборки в корне проекта выполните:

```bash
flutter pub get
flutter run
flutter build apk --release
```

Готовый APK появится по пути `build/app/outputs/flutter-apk/app-release.apk`. GitHub Actions также собирает APK после каждого push в `main`; его можно скачать из раздела Actions как артефакт `hyperion-drone-controller-apk`.

## Этапы

1. Версия 0.1: экран с демонстрационными кнопками.
2. Версия 0.2: выбор Wi-Fi сети квадрокоптера и отображение текущей сети.
3. Версия 0.3: первоначальная проверка ответа дрона по Wi-Fi.
4. Версия 0.4: задержка и контроль пропадания подтверждённого ответа.
5. Версия 0.5: остановка сессии вручную и при сворачивании приложения.
6. Версия 0.6: интерфейсный макет выбора одного мотора.
7. Версия 0.7: четыре независимые симуляции моторов и общая остановка.
8. Полную версию приложения добавляет её автор отдельным коммитом.
